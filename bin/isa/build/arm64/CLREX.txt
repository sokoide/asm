CLREX {#imm} — ARM64（データ転送）

ローカルの排他モニタを解除する。

アドレッシング: 暗黙
フラグ: N-  Z-  C-  V-

────────────── 詳細 ──────────────

消費クロック:
  ISA では規定されない: 実装依存

オペコード:
  CLREX #imm4: 11010101000000110011 imm4 01011111  (4 バイト)

使用例:
  ldxr  w0, [x1]            // 排他モニタを設定
  cbnz  w0, abort           // 値が期待と違えば更新を中止
  stxr  w2, w3, [x1]        // 新値 w3 の排他書き込みを試みる
  b     done                // 成否は w2 で判定して先へ進む
  abort:
    clrex                   // 不要になった排他モニタを明示的に解除
  done:

解説:
  LDXR/LDAXR で設定したローカルの排他モニタを解除する。排他ロード後に条件不一致などで STXR を行わず中断する場合のクリーンアップに使う。

備考:
  即値は省略可能。排他アクセス列の中断時などに使う。

（根拠: note）
