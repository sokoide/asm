mftbu（拡張ニーモニック）→ MFSPR rT, SPR — PowerPC（レジスタ管理）

Time Base 上位ワードからの移動（Move from Time Base Upper）

アドレッシング: レジスタ
フラグ: LT-  GT-  EQ-  SO-

────────────── 詳細 ──────────────

拡張形式:
  mftbu rT ⇔ mfspr rT, 269
  Time Base 上位ワードからの移動（Move from Time Base Upper）
  SPR 269 を読む。

使用例:
  mftbu 3

解説:
  この例では Time Base 上位ワードからの移動（Move from Time Base Upper）

元命令: isa ppc MFSPR
特殊目的レジスタ（LR/CTR/XER など）からの読出し。拡張形式は mflr/mfctr/mfxer。

消費クロック:
  440 コア: 1

オペコード:
  mfspr rT,SPR: 011111 rT SPR[0:4] SPR[5:9] 0101010011 0  (4 バイト)

使用例:
  mfspr %r3,8

解説:
  この例では 特殊目的レジスタ（LR/CTR/XER など）からの読出し。拡張形式は mflr/mfctr/mfxer。

備考:
  LR=8、CTR=9、XER=1。mfdcr/mtdcr は Book E（440）のデバイス制御レジスタアクセス（特権）。
