CLI — 80386（システム制御）

割り込み許可フラグ IF を 0 にする（マスク可能割り込みを禁止）。

アドレッシング: 暗黙
フラグ: O-  D-  I0  S-  Z-  A-  P-  C-

────────────── 詳細 ──────────────

消費クロック:
  常時: 3

オペコード:
  CLI: FA  (1 バイト)

使用例:
  cli

解説:
  IF = 0 にしてマスク可能割り込みを禁止する。

備考:
  プロテクトモードでは CPL>IOPL で #GP。仮想 8086 モードでは IOPL<3 のとき #GP。NMI は禁止しない。

（根拠: book）
