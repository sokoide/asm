CLI — 8086（フラグ操作）

割り込みフラグ IF を 0 にしてマスク可能割り込みを禁止する。8086 には特権レベルはない。

アドレッシング: 暗黙
フラグ: O-  D-  I0  S-  Z-  A-  P-  C-

────────────── 詳細 ──────────────

消費クロック:
  常時: 2

オペコード:
  CLI: FA  (1 バイト)

使用例:
  cli                       ; IF = 0（マスク可能割り込みを禁止）
  ; クリティカルセクション（共有データや割り込みベクタの書き換え）
  sti                       ; IF = 1（割り込み許可に戻す）

解説:
  割り込みフラグ IF を 0 にしてマスク可能割り込み（INTR）を禁止する（NMI は禁止されない）。

（根拠: book）
