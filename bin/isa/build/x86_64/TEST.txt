TEST dst, src — x86-64（比較）

dst AND src を計算してフラグのみ更新する（dst は不変）。ビットの有無やゼロ判定に使う。

アドレッシング: レジスタ、即値、間接(base+index×scale+disp)
フラグ: O0  D-  I-  S‡  Z‡  AU  P‡  C0

────────────── 詳細 ──────────────

消費クロック:
  CPU・実行条件に依存: 実装依存

オペコード:
  TEST r/m64, r64: REX.W 85 /r  (長さ可変)
  TEST r/m64, imm32: REX.W F7 /0 id  (長さ可変)

使用例:
  test rax, rbx

解説:
  rax AND rbx を計算してフラグのみ更新する。rax は不変で CF = OF = 0。

備考:
  test reg, reg は「レジスタが 0 か」の判定イディオム。
