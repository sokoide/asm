bnulr（拡張ニーモニック）→ BCLR BO, BI — PowerPC（分岐）

順序付けなしでないときLRへ分岐（Branch if Not Unordered to LR）

アドレッシング: レジスタ間接（LR）
フラグ: LT-  GT-  EQ-  SO-

────────────── 詳細 ──────────────

拡張形式:
  bnulr [crT] ⇔ bclr 0x04, (crT*4)+3
  順序付けなしでないときLRへ分岐（Branch if Not Unordered to LR）
  [l] 接尾でリンク（LR 更新）。crT を省略すると CR0。 浮動小数点比較の結果用。

使用例:
  bnulr

解説:
  この例では 順序付けなしでないときLRへ分岐（Branch if Not Unordered to LR）

元命令: isa ppc BCLR
LR への条件分岐。blr 拡張形式（bclr 20,0）が関数復帰の標準。

消費クロック:
  440 コア（fold 時）: 0

オペコード:
  bclr BO,BI: 010011 BO BI 00000 0000010000 LK  (4 バイト)

使用例:
  bclr 12,2

解説:
  この例では LR への条件分岐。blr 拡張形式（bclr 20,0）が関数復帰の標準。

備考:
  btlr/bflr などの拡張形式がある。bclrl は分岐先として更新前の LR を使い、分岐の成否にかかわらず次の命令のアドレスを LR に設定する。
