SHL dst, count — x86-64（シフト）

左論理シフト。上位ビットを C に送り出し、下位に 0 を詰める。×2^count に相当。SAL と同一。

アドレッシング: レジスタ、間接(base+index×scale+disp)、CL によるビット数指定、即値によるビット数指定
フラグ: O‡  D-  I-  S‡  Z‡  AU  P‡  C‡

────────────── 詳細 ──────────────

消費クロック:
  reg, 1 ビット: 1
  reg, CL: 1〜3
  メモリオペランド: 3〜5

オペコード:
  SHL r/m64, 1: REX.W D1 /4  (3 バイト)
  SHL r/m64, imm8: REX.W C1 /4 ib  (4 バイト)
  SHL r/m64, CL: REX.W D3 /4  (3 バイト)

備考:
  count は 64bit では mod 64、32bit では mod 32 で使われる。
  count=1 のときのみ OF が定義（結果の MSB と C の XOR）、count≠0 なら S/Z/P 更新。count=0 ならフラグ不変。
  シフトアウトしたビットが C に入るため、ビットテストに使える（本書12章）。
