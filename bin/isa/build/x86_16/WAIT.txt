WAIT — 8086（システム制御）

TEST 入力が所定の状態になるまで待機する。8087 の処理完了との同期に使う。

アドレッシング: 暗黙
フラグ: O-  D-  I-  S-  Z-  A-  P-  C-

────────────── 詳細 ──────────────

消費クロック:
  常時: 3+5n

オペコード:
  WAIT: 9B  (1 バイト)

使用例:
  status_word: dw 0             ; FPU ステータスの受け口
  fstsw [status_word]       ; 8087 FPU のステータスをメモリへ書込み
  wait                      ; 8087 の処理完了（TEST ピン）まで CPU を待機

解説:
  外部 TEST 入力が所定の状態になるまで待機し、8087 数値コプロセッサの処理完了と CPU のメモリアクセスを同期する。

備考:
  待機の有無は外部 TEST 入力に依存する。クロックはテスト待ち回数 n で 3+5n。

（根拠: book）
