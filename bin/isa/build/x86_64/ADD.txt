ADD dst, src — x86-64（算術）

dst に src を加算する。符号なし桁上がりは C、符号付きオーバーフローは O で検出。

アドレッシング: レジスタ、即値、間接(base+index×scale+disp)
フラグ: O‡  D-  I-  S‡  Z‡  A‡  P‡  C‡

────────────── 詳細 ──────────────

消費クロック:
  CPU・実行条件に依存: 実装依存

オペコード:
  ADD r/m64, r64: REX.W 01 /r  (長さ可変)
  ADD r/m64, imm32: REX.W 81 /0 id  (長さ可変)
  ADD r/m64, imm8: REX.W 83 /0 ib  (長さ可変)

使用例:
  add rax, rbx

解説:
  rax = rax + rbx。OF/SF/ZF/AF/PF/CF を更新。

備考:
  imm8 形（83 /0）は符号拡張されるため 2〜3 バイト短い。
  多倍長加算は下位ワードから ADC を連結する。
