INT n — x86-64（サブルーチン）

ソフトウェア割り込みを発生させる。IDT の n 番ゲートへ制御を移す。INT3（CC）は 1 バイトのブレークポイント。

アドレッシング: 即値
フラグ: O-  D-  I‡  S-  Z-  A-  P-  C-

────────────── 詳細 ──────────────

消費クロック:
  CPU・実行条件に依存: 実装依存

オペコード:
  INT imm8: CD ib  (2 バイト)
  INT3: CC  (1 バイト)

使用例:
  int 0x10

解説:
  この例では ソフトウェア割り込みを発生させる。IDT の n 番ゲートへ制御を移す。INT3（CC）は 1 バイトのブレークポイント。

備考:
  64 ビットモードのゲート通過時は SS/RSP と RFLAGS/CS/RIP がスタックに積まれる。TF はクリアされ、IF は割り込みゲートではクリア、トラップゲートでは保持される。
  旧 32bit Linux は int 0x80 でシステムコールを行っていた（64bit では SYSCALL）。
