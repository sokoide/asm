PUSH src — 80386（スタック）

スタックポインタをオペランドサイズ分だけ減算し、レジスタ・メモリ・即値・セグメント値を格納する。

アドレッシング: レジスタ、即値、間接(base+index×scale+disp)
フラグ: O-  D-  I-  S-  Z-  A-  P-  C-

────────────── 詳細 ──────────────

消費クロック:
  reg / 即値 / セグメントレジスタ: 2
  mem: 5

オペコード:
  PUSH r16/32: 50+r  (長さ可変)
  PUSH imm32 / imm16（32bit モード）: 68 id / 66 68 iw  (長さ可変)
  PUSH imm8: 6A ib  (2 バイト)
  PUSH Sreg: 06/0E/16/1E（FS: 0F A0、GS: 0F A8）  (長さ可変)
  PUSH r/m16/32: FF /6  (長さ可変)

使用例:
  push eax

解説:
  esp を 4 減算し、eax の値をスタック頂点 [esp] へ格納する。

備考:
  80186 以降は即値 PUSH が可能。imm8 はオペランド幅へ符号拡張する。80386 の PUSH SP/ESP は命令実行前の値を積む。オペランドサイズで積む幅、スタックアドレスサイズで SP/ESP のどちらを使うかが決まる。
