CMP src — 6502（比較）

A と src を比較（A - src のフラグのみ反映、A は不変）。Z80 と違い C=1 が符号なし比較で「A >= src」。

アドレッシング: 即値、ゼロページ、ゼロページ,X、絶対、絶対,X、絶対,Y、(ゼロページ,X)、(ゼロページ),Y
フラグ: N‡  V-  D-  I-  Z‡  C‡

────────────── 詳細 ──────────────

消費クロック:
  imm: 2
  zp: 3
  zp,x: 4
  abs: 4
  abs,x / abs,y（ページ境界 +1）: 4
  (zp,x): 6
  (zp),y（ページ境界 +1）: 5

オペコード:
  CMP #n: C9  (2 バイト)
  CMP zp: C5  (2 バイト)
  CMP zp,x: D5  (2 バイト)
  CMP abs: CD  (3 バイト)
  CMP abs,x: DD  (3 バイト)
  CMP abs,y: D9  (3 バイト)
  CMP (zp,x): C1  (2 バイト)
  CMP (zp),y: D1  (2 バイト)

使用例:
  lda $20
  cmp #$10
  bcc below      ; A < $10（C=0）なら減算をスキップ
  sec
  sbc #$10       ; A >= $10 のときだけ実行
  below:

解説:
  A と $10 を符号なし比較し、A < $10 なら減算をスキップして below へ分岐する。CMP は A を変えない。

備考:
  符号なし比較で C=1 は A >= src、C=0 は A < src。BCC/BCS と組み合わせる。N は 8 ビット減算結果の符号ビットであり、V は更新されないため N だけでは一般に符号付き大小を判定できない。
