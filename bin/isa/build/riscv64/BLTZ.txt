BLTZ rs, offset — RISC-V 64（分岐）

rs が符号付きで 0 未満なら分岐する。

アドレッシング: PC相対

────────────── 詳細 ──────────────

消費クロック:
  ISA では規定されない: 実装依存

使用例:
  bltz t1, is_neg           # t1 < 0（符号付き）なら処理をスキップ
  addi t0, t0, 1            # t1 >= 0 のときだけ実行
  is_neg:

解説:
  t1 < 0（符号付き）なら後続処理をスキップして is_neg へ分岐する（blt t1, zero, is_neg に展開される疑似命令）。

備考:
  疑似命令。BLT rs,x0,offset に展開する。変位は分岐命令のアドレスを基準とし、範囲は -4096〜+4094 バイト（2 バイト単位）。
