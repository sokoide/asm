CPX src — 6502（比較）

X と src を比較。C=1 が符号なし比較で「X >= src」。

アドレッシング: 即値、ゼロページ、絶対
フラグ: N‡  V-  D-  I-  Z‡  C‡

────────────── 詳細 ──────────────

消費クロック:
  imm: 2
  zp: 3
  abs: 4

オペコード:
  CPX #n: E0  (2 バイト)
  CPX zp: E4  (2 バイト)
  CPX abs: EC  (3 バイト)

使用例:
  ldx $20
  cpx #$10
  bcs at_least   ; X >= $10（C=1）なら初期化をスキップ
  ldx #$10       ; X < $10 のとき下限値に補正
  at_least:

解説:
  X と $10 を符号なし比較し、X >= $10 なら補正処理をスキップして at_least へ分岐する。
