TBZ src, #bit, label — ARM64（分岐）

指定ビットが 0 なら相対分岐する。NZCV は変更しない。範囲は命令アドレスから -32,768〜+32,764 バイト。

アドレッシング: 相対分岐
フラグ: N-  Z-  C-  V-

────────────── 詳細 ──────────────

消費クロック:
  ISA では規定されない: 実装依存

オペコード:
  TBZ Rt,#bit,label: b5 011011 0 b40 imm14 Rt  (4 バイト)

使用例:
  tbz w0, #3, bit3_clear    // bit3 == 0 なら処理をスキップ（フラグ不変）
  mov w1, #1                // bit3 == 1 のときだけ実行
  bit3_clear:

解説:
  w0 のビット #3 が 0 なら後続処理をスキップして bit3_clear へ分岐し、1 なら次の命令へ進む。フラグレジスタを変更せず単一ビットをテスト分岐できる。

備考:
  ビット番号は W レジスタ指定なら 0〜31、X レジスタ指定なら 0〜63。 b5:b40 は 6 ビットのビット番号。imm14 は符号付きで 4 バイト単位。
