ADD dst, src1, src2{, shift} — ARM64（算術）

加算（レジスタ/即値、LSL/LSR 等のシフト付き）。フラグは変化しない。

アドレッシング: レジスタ、即値（0〜4095、12 ビット左シフト可）、シフト付きレジスタ、拡張レジスタ（uxtb/sxtw など）
フラグ: N-  Z-  C-  V-

────────────── 詳細 ──────────────

消費クロック:
  ISA では規定されない: 実装依存

オペコード:
  ADD Rd,Rn,#imm12{,LSL #12}: sf 0 0 10001 0 sh imm12 Rn Rd  (4 バイト)
  ADD Rd,Rn,Rm{,shift #amount}: sf 0 0 01011 shift 0 Rm imm6 Rn Rd  (4 バイト)
  ADD Rd,Rn,Rm,extend{ #amount}: sf 0 0 01011 00 1 Rm option imm3 Rn Rd  (4 バイト)

使用例:
  add x0,x1,#1,lsl #12

解説:
  x0 = x1 + (#1 を 12 ビット左シフトした値)。フラグは変化しない。

備考:
  フラグが必要なら ADDS。即値形式は 12 ビット即値をそのまま、または 12 ビット左シフトして使う。 即値 sh=0 は無シフト、sh=1 は 12 ビット左シフト。シフト形式の shift は LSL=00、LSR=01、ASR=10。拡張形式の option は拡張方式、imm3 は左シフト 0〜4。SP を使えるオペランド位置は形式とフラグ更新の有無で異なる。
