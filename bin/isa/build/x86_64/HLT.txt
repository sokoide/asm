HLT — x86-64（システム制御）

CPU を停止状態にする。割り込み・NMI・RESET で再開する。特権命令。

アドレッシング: 暗黙
フラグ: O-  D-  I-  S-  Z-  A-  P-  C-

────────────── 詳細 ──────────────

消費クロック:
  CPU・実行条件に依存: 実装依存

オペコード:
  HLT: F4

使用例:
  idle:
    hlt                     ; 割り込み・NMI・RESET まで CPU を停止（Ring 0 特権命令）
    jmp idle

解説:
  CPU を停止状態にし、割り込み・NMI・RESET で再開する（Ring 0 特権命令）。OS のアイドルループで使われる。

備考:
  Ring 0 用。ユーザーモードで実行すると #GP。

（根拠: book）
