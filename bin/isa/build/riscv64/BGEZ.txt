BGEZ rs, offset — RISC-V 64（分岐）

rs が符号付きで 0 以上なら分岐する。

アドレッシング: PC相対

────────────── 詳細 ──────────────

消費クロック:
  ISA では規定されない: 実装依存

使用例:
  bgez t1, non_neg          # t1 >= 0（符号付き）なら負数補正をスキップ
  neg  t1, t1               # t1 < 0 のときだけ絶対値化
  non_neg:

解説:
  t1 >= 0（符号付き）なら負数補正をスキップして non_neg へ分岐する（bge t1, zero, non_neg に展開される疑似命令）。

備考:
  疑似命令。BGE rs,x0,offset に展開する。変位は分岐命令のアドレスを基準とし、範囲は -4096〜+4094 バイト（2 バイト単位）。
