bl（拡張ニーモニック）→ B target — PowerPC（分岐）

戻り先を LR に記録して分岐（Branch with Link）

アドレッシング: 相対（AA=0）、絶対（ba/bla）
フラグ: LT-  GT-  EQ-  SO-

────────────── 詳細 ──────────────

拡張形式:
  bl target ⇔ b target (LK=1)
  戻り先を LR に記録して分岐（Branch with Link）
  B 形式の LK ビットを1にする。

使用例:
  bl  callee                # LR に戻りアドレスを保存して callee を呼び出し
  mr  %r4, %r3              # blr 後にここへ戻る
  b   done                  # callee へフォールスルーしない
  callee:
    li  %r3, 42
    blr
  done:

解説:
  次の命令のアドレスを LR へ記録して callee へ分岐する（b callee の LK=1 版）。関数呼び出しの標準形。

元命令: isa ppc B
無条件分岐（I-Form）。相対分岐の範囲は命令アドレスから -33,554,432〜+33,554,428 バイト。

消費クロック:
  440 コア（fold 時）: 0

オペコード:
  b / ba / bl / bla: 18  (4 バイト)

使用例:
  b   skip
  li  %r3, -1               # 分岐するため実行されない
  skip:
  li  %r3, 0

解説:
  途中の処理を飛ばして skip へ無条件に相対分岐する（相対範囲は命令アドレスから -33,554,432〜+33,554,428 バイト）。bl で LR 更新、ba/bla で絶対アドレス指定になる。

備考:
  bl は次命令のアドレスを LR に保存する。ba/bla は符号拡張された絶対アドレスを指定する。

（根拠: book）
