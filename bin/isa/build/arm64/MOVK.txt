MOVK dst, #imm16{, LSL #shift} — ARM64（データ転送）

16 ビット即値を指定シフト位置に上書き（他のビットは保持）。64 ビット即値の組み立て用。

アドレッシング: 即値
フラグ: N-  Z-  C-  V-

────────────── 詳細 ──────────────

消費クロック:
  ISA では規定されない: 実装依存

オペコード:
  MOVK Rd,#imm16{,LSL #shift}: sf 11 100101 hw imm16 Rd  (4 バイト)

使用例:
  movz x0, #0x5678          // x0 = 0x0000000000005678
  movk x0, #0x1234, lsl #16 // x0 = 0x0000000012345678（下位 16 ビットは保持）

解説:
  下位ビットを保持したまま x0 のビット 31〜16 を即値 #0x1234 で上書きする。MOVZ と MOVK を組み合わせることで任意の 32/64 ビット定数を組み立てられる。

備考:
  MOVZ と MOVK の組合せが 64 ビット即値ロードの定番（adr/litpool に次ぐ方法）。 sf=0 は W レジスタ、sf=1 は X レジスタ。hw は 16 ビット単位のシフト量を表す（W は 0〜1、X は 0〜3）。
