STI — x86-64（システム制御）

割り込み許可フラグ IF を 1 にする（マスク可能割り込みを許可）。

アドレッシング: 暗黙
フラグ: O-  D-  I1  S-  Z-  A-  P-  C-

────────────── 詳細 ──────────────

消費クロック:
  CPU・実行条件に依存: 実装依存

オペコード:
  STI: FB  (1 バイト)

使用例:
  sti                       ; IF = 1（マスク可能割り込みを許可、CPL <= IOPL）

解説:
  IF を 1 にしてマスク可能割り込みを許可する（CPL <= IOPL）。CLI で区切った割り込み禁止区間の解除が定石で、効力は直後の命令の実行を待って有効になる。

備考:
  sti の次の 1 命令は割り込みが抑止される（ret 前の sti で安全に戻れる）。
