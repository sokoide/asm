PHP — 6502（スタック）

フラグレジスタ P をスタックに PUSH する。

アドレッシング: スタック
フラグ: N-  V-  D-  I-  Z-  C-

────────────── 詳細 ──────────────

消費クロック:
  常時: 3

オペコード:
  PHP: 08  (1 バイト)

使用例:
  php
  ; ... フラグが変わる処理 ...
  plp

解説:
  処理前のフラグレジスタ P をスタックへ退避し、あとで PLP で復元する。PHP/PLP の対はスタック順を崩さないよう対応させる。

備考:
  PHP が積む P の bit4 と bit5 は 1。B は独立した物理フラグではなく、PLP/RTI では bit4・bit5 をフラグとして復帰しない。
