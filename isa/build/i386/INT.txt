INT n — 80386（サブルーチン）

ソフトウェア割り込みを発生させる。IDT の n 番ゲートへ制御を移す。INT3（CC）は 1 バイトのブレークポイント。

アドレッシング: 即値
フラグ: O-  D-  I0  S-  Z-  A-  P-  C-

────────────── 詳細 ──────────────

消費クロック:
  INT n / INT3（ゲート経由）: 30〜80

オペコード:
  INT imm8: CD ib  (2 バイト)
  INT3: CC  (1 バイト)

備考:
  ゲート通過で EFLAGS/CS/EIP（特権変化時は SS/ESP も）がスタックに積まれ、TF と IF がクリアされる。
  INTO は OF=1 のときだけベクタ 4 への割り込み（未成立なら 4 クロックで無視）。
  DOS や旧 Linux（int 0x80）のシステムコール入口。

（根拠: note）
