ADC dst, src — x86-64（算術）

キャリー込み加算。dst = dst + src + C。多倍長加算の上位ワード処理に使う。

アドレッシング: レジスタ、即値、間接(base+index×scale+disp)
フラグ: O‡  D-  I-  S‡  Z‡  A‡  P‡  C‡

────────────── 詳細 ──────────────

消費クロック:
  CPU・実行条件に依存: 実装依存

オペコード:
  ADC r/m64, r64: REX.W 11 /r  (長さ可変)
  ADC r/m64, imm32: REX.W 81 /2 id  (長さ可変)

使用例:
  adc rax, rbx

解説:
  rax = rax + rbx + CF。OF/SF/ZF/AF/PF/CF を更新。

備考:
  多倍長加算の定形: add 下位 → adc 上位。
