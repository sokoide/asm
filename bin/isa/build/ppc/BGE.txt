bge（拡張ニーモニック）→ BC BO, BI, target — PowerPC（分岐）

以上のとき分岐（Branch if Greater Than or Equal）

アドレッシング: 相対、絶対（bca）
フラグ: LT-  GT-  EQ-  SO-

────────────── 詳細 ──────────────

拡張形式:
  bge [crT,]addr ⇔ bc 0x04, (crT*4)+0, addr
  以上のとき分岐（Branch if Greater Than or Equal）
  [l] 接尾でリンク（LR 更新）、[a] 接尾で絶対アドレス分岐。条件コード用の CR フィールド指定を省略すると CR0。

使用例:
  bge target
  target:

解説:
  cr0 の LT が 0 のとき target へ分岐する（bc 0x04,0,target の簡記）。

元命令: isa ppc BC
条件付き分岐（B-Form）。BO/BI の組合せで CTR 減算・CR ビットテストを制御する。

消費クロック:
  440 コア（fold 時）: 0

オペコード:
  bc BO,BI,BD: 010000 BO BI BD AA LK  (4 バイト)

使用例:
  bc 12,2,target
  target:

解説:
  BO=12（CR ビット=1 で分岐）× BI=2（cr0 の EQ ビット）なので、cr0 の EQ=1 のとき target へ分岐する（beq 相当）。BO/BI の組合せで CTR 減算と CR テストを制御する。

備考:
  相対分岐の範囲は命令アドレスから -32,768〜+32,764 バイト。BO=16 は CTR 減算後に非ゼロなら分岐、12 は CR 真、4 は CR 偽、20 は CTR 減算も CR 判定もしない無条件分岐。bdnz/bdz などは拡張形式。LK=1 の形式は、分岐の成否にかかわらず次命令のアドレスを LR に設定する。
