BEQZ rs, offset — RISC-V 32（分岐）

rs == 0 なら PC 相対オフセットへ分岐する疑似命令。

アドレッシング: PC相対

────────────── 詳細 ──────────────

消費クロック:
  ISA では規定されない: 実装依存

使用例:
  beqz t1, is_zero          # t1 == 0 なら加算をスキップ
  addi t0, t0, 1            # t1 != 0 のときだけ実行
  is_zero:

解説:
  t1 == 0 なら後続処理をスキップして is_zero へ分岐する（beq t1, zero, is_zero に展開される疑似命令）。

備考:
  BEQ rs, x0, offset に展開される。
