INT n — x86-64（サブルーチン）

ソフトウェア割り込みを発生させる。IDT の n 番ゲートへ制御を移す。INT3（CC）は 1 バイトのブレークポイント。

アドレッシング: 即値
フラグ: O-  D-  I0  S-  Z-  A-  P-  C-

────────────── 詳細 ──────────────

消費クロック:
  実装依存（ゲート処理込み）: 実装依存

オペコード:
  INT imm8: CD ib  (2 バイト)
  INT3: CC  (1 バイト)

備考:
  ゲート通過時に RFLAGS/CS/RIP（必要に応じ SS/RSP）がスタックに積まれ、TF と IF がクリアされる。
  旧 32bit Linux は int 0x80 でシステムコールを行っていた（64bit では SYSCALL）。

（根拠: note）
