CLC — x86-64（フラグ操作）

キャリーフラグ C を 0 にクリアする。

アドレッシング: 暗黙
フラグ: O-  D-  I-  S-  Z-  A-  P-  C0

────────────── 詳細 ──────────────

消費クロック:
  CPU・実行条件に依存: 実装依存

オペコード:
  CLC: F8  (1 バイト)

使用例:
  clc                       ; CF = 0

解説:
  キャリーフラグ C を 0 にクリアする（ADC/SBB/RCL/RCR の事前初期化に使う）。

備考:
  adc/sbb/rcl/rcr の前の初期化。
