SET b, r — Z80（シフト/ビット）

レジスタ/メモリのビット b を 1 にする。

アドレッシング: レジスタ、レジスタ間接、インデックス(IX/IY+d)
フラグ: S-  Z-  H-  P/V-  N-  C-

────────────── 詳細 ──────────────

消費クロック:
  SET b,r: 8
  SET b,(HL): 15
  SET b,(IX/IY+d): 23

オペコード:
  SET b,r: CB 11BBBSSS  (2 バイト)
  SET b,(HL): CB 11BBB110  (2 バイト)
  SET b,(IX+d): DD CB d 11BBB110  (4 バイト)
  SET b,(IY+d): FD CB d 11BBB110  (4 バイト)

使用例:
  set 3,b

解説:
  この例では レジスタ/メモリのビット b を 1 にする。

備考:
  フラグは一切変化しない。

（根拠: book）
