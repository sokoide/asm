Jcc label — x86-64（分岐）

条件付きジャンプ。フラグの状態をテストして成立時のみ rel8/rel32 のターゲットへ分岐する（16 種類の条件）。

アドレッシング: 相対分岐(short/near)
フラグ: O-  D-  I-  S-  Z-  A-  P-  C-

────────────── 詳細 ──────────────

消費クロック:
  分岐予測成功: 1〜2
  分岐予測ミス: 実装依存

オペコード:
  Jcc rel8: 70+cc cb  (2 バイト)
  Jcc rel32: 0F 80+cc cd  (6 バイト)

備考:
  cc は 0=O 1=NO 2=B 3=AE 4=E 5=NE 6=BE 7=A 8=S 9=NS A=P B=NP C=L D=GE E=LE F=G。
  主な別名: je=jz / jne=jnz / jb=jc=jnae / jae=jnc=jnb / jbe=jna / ja=jnbe / jl=jnge / jge=jnl / jle=jng / jg=jnle / jp=jpe / jnp=jpo。
  符号付きは SF と O、符号なしは C と Z で判定。

（根拠: book）
