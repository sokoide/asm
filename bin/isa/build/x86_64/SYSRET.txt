SYSRET — x86-64（サブルーチン）

システムコールからユーザーへ復帰する。64 ビット形式は RIP を RCX から復帰し、R11 を基に RFLAGS を復帰する。

アドレッシング: 暗黙
フラグ: O‡  D‡  I‡  S‡  Z‡  A‡  P‡  C‡

────────────── 詳細 ──────────────

消費クロック:
  CPU・実行条件に依存: 実装依存

オペコード:
  SYSRET: 0F 07  (2 バイト)

使用例:
  ; RCX にユーザー空間の戻り先 RIP、R11 に復帰後 RFLAGS を設定済み（Ring 0）
  o64 sysret                ; CPL 0 から CPL 3 のユーザー空間へ高速復帰（48 0F 07）

解説:
  システムコールからユーザー空間（CPL 3）へ復帰する特権命令。64 ビット形式は RIP を RCX から、RFLAGS を R11 から復元する。

備考:
  特権命令（Ring 0 のみ）。64 ビット形式では RCX はカノニカルアドレスでなければならない。RSP は変更されないため、必要な復帰は OS が行う。
