SYSENTER — x86-64（システム制御）

SYSENTER 用 MSR と OS の規約に従い、高速な特権レベル遷移を行う。

アドレッシング: 暗黙
フラグ: O-  D-  I0  S-  Z-  A-  P-  C-

────────────── 詳細 ──────────────

消費クロック:
  CPU・実行条件に依存: 実装依存

オペコード:
  SYSENTER: 0F 34  (2 バイト)

使用例:
  sysenter

解説:
  この例では SYSENTER 用 MSR と OS の規約に従い、高速な特権レベル遷移を行う。

備考:
  リアルアドレスモード以外で実行可能。CPL 3 のユーザーコードからも呼び出せ、IA32_SYSENTER_CS/ESP/EIP MSR で設定したCPL 0 の入口へ移行する。EFLAGS.VM と IF をクリアする。戻り先やユーザー状態は保存しないため、復帰情報は呼出側・OS間の規約で扱う。
