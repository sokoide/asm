INT n — 80386（サブルーチン）

ソフトウェア割り込みを発生させる。IDT の n 番ゲートへ制御を移す。INT3（CC）は 1 バイトのブレークポイント。

アドレッシング: 即値
フラグ: O-  D-  I‡  S-  Z-  A-  P-  C-

────────────── 詳細 ──────────────

消費クロック:
  INT 3、リアルモード: 33
  INT imm8、リアルモード: 37
  プロテクトモード同一特権: 59
  プロテクトモード内側の特権へ移行: 99
  仮想 8086 から特権レベル 0 へ移行: 119
  タスクゲート経由: 条件による

オペコード:
  INT imm8: CD ib  (2 バイト)
  INT3: CC  (1 バイト)

使用例:
  int 0x10

解説:
  ベクタ 0x10 の IDT ゲート経由で割り込みハンドラへ制御を移す。

備考:
  ゲート通過で EFLAGS/CS/EIP（特権変化時は SS/ESP も）がスタックに積まれ、TF はクリアされ、IF は割り込みゲートではクリア、トラップゲートでは保持される。
  INTO は OF=1 のときだけベクタ 4 への割り込み（未成立なら 3 クロックで無視）。
  DOS や旧 Linux（int 0x80）のシステムコール入口。

（根拠: note）
