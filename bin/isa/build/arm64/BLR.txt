BLR Xn — ARM64（サブルーチン）

レジスタ間接サブルーチン呼び出し。次の命令のアドレスを X30（LR）に保存する。

アドレッシング: レジスタ間接
フラグ: N-  Z-  C-  V-

────────────── 詳細 ──────────────

消費クロック:
  ISA では規定されない: 実装依存

オペコード:
  BLR Xn: 1101011000111111000000 Rn 00000  (4 バイト)

使用例:
  adr x1, callee            // 呼び出し先アドレスを x1 に取得
  blr x1                    // x30 に戻り先を保存し、x1 のアドレスを呼び出し
  mov w1, w0                // callee の RET でここへ戻る
  b   done                  // callee へフォールスルーしない
  callee:
    mov w0, #42
    ret
  done:

解説:
  次の命令のアドレスを x30（LR）に保存し、x1 に格納されたアドレスへ間接呼び出しする。関数ポインタや仮想関数テーブルの呼び出しに使う。
