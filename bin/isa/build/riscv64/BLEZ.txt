BLEZ rs, offset — RISC-V 64（分岐）

rs が符号付きで 0 以下なら分岐する。

アドレッシング: PC相対

────────────── 詳細 ──────────────

消費クロック:
  ISA では規定されない: 実装依存

使用例:
  blez t1, non_pos          # t1 <= 0（符号付き）なら処理をスキップ
  addi t0, t0, 1            # t1 > 0 のときだけ実行
  non_pos:

解説:
  t1 <= 0（符号付き）なら後続処理をスキップして non_pos へ分岐する（bge zero, t1, non_pos に展開される疑似命令）。

備考:
  疑似命令。BGE x0,rs,offset に展開する。変位は分岐命令のアドレスを基準とし、範囲は -4096〜+4094 バイト（2 バイト単位）。
