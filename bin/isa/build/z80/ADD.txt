ADD A, r — Z80（算術）

A に r（または (HL)、即値）を加算し結果を A に入れる。16 ビット版は ADD HL,ss / ADD IX,pp / ADD IY,rr。

アドレッシング: レジスタ、レジスタ間接、インデックス(IX/IY+d)、即値
フラグ: S‡  Z‡  H‡  P/V‡  N0  C‡

────────────── 詳細 ──────────────

消費クロック:
  ADD A,r: 4
  ADD A,(HL): 7
  ADD A,n: 7
  ADD (IX/IY+d): 19
  ADD HL,ss: 11
  ADD IX/IY,pp: 15

オペコード:
  ADD A,r: 10000SSS  (1 バイト)
  ADD A,n: C6 n  (2 バイト)
  ADD HL,ss: 09/19/29/39  (1 バイト)
  ADD A,(HL): 86  (1 バイト)
  ADD A,(IX+d): DD 86 d  (3 バイト)
  ADD A,(IY+d): FD 86 d  (3 バイト)
  ADD IX,pp: DD 00pp1001  (2 バイト)
  ADD IY,rr: FD 00rr1001  (2 バイト)

備考:
  ss は BC/DE/HL/SP。IX 版は BC/DE/IX/SP、IY 版は BC/DE/IY/SP を使う。上のフラグ欄は 8 ビット形式で、16 ビット形式は S/Z/P-V を保持し、H/C を更新し N=0 とする。8 ビット算術演算時の P/V はオーバーフローとして機能する。
