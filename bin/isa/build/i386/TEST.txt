TEST dst, src — 80386（比較）

dst AND src を計算してフラグのみ更新する（dst は不変）。ビットの有無やゼロ判定に使う。

アドレッシング: レジスタ、即値、間接(base+index×scale+disp)
フラグ: O0  D-  I-  S‡  Z‡  AU  P‡  C0

────────────── 詳細 ──────────────

消費クロック:
  レジスタ同士 / reg, 即値: 2
  mem, reg / mem, 即値: 5

オペコード:
  TEST r/m, r: 85 /r（8bit は 84 /r）  (長さ可変)
  TEST r/m8, imm8: F6 /0 ib  (長さ可変)
  TEST r/m16/32, imm16/32: F7 /0 iw/id  (長さ可変)
  TEST AL, imm8: A8 ib  (長さ可変)
  TEST AX/EAX, imm16/32: A9 iw/id  (長さ可変)

使用例:
  test eax, ebx

解説:
  この例では dst AND src を計算してフラグのみ更新する（dst は不変）。ビットの有無やゼロ判定に使う。

備考:
  test reg, reg はゼロ判定のイディオム。
